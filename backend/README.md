# MG Arts – Backend (Node + Express + MongoDB)

    npm install
    cp .env.example .env      # set JWT_SECRET / MONGO_URI
    npm run seed              # permissions, Admin/Staff roles, admin user, tax rates
    npm run seed:demo         # (optional) + sample customers, workers and a full gold flow
    npm run dev               # http://localhost:5000/api

Default login: admin@mgarts.com / Admin@123 (change it in .env before seeding, or in Profile).
